# Security Policy

PXHash is a C++ container library. Please report memory-safety, undefined-behavior, build-chain, or supply-chain issues privately.

Supported versions:

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

To report a vulnerability, open a private security advisory on GitHub or contact the maintainer directly. Include:

- affected commit or release
- compiler, platform, and build flags
- minimal reproducer
- sanitizer output when available

Please do not publish exploit details before a fix is available.
